Q6. HR APPLICATION
=======================================================

PROJECT:
SADPA4/hrapp

PORT:
8080

RUN COMMAND:
cd SADPA4/hrapp
mvn spring-boot:run


1. OPEN APPLICATION
-------------------
Browser:

http://localhost:8080/

Normally redirects to:

http://localhost:8080/employees


2. DISPLAY EMPLOYEES
--------------------
Browser:

http://localhost:8080/employees


3. NEW EMPLOYEE FORM
--------------------
Browser:

http://localhost:8080/employees/new


4. SAVE EMPLOYEE
----------------
Form submits:

POST
http://localhost:8080/employees/save

Use the HTML form.


5. DELETE EMPLOYEE
------------------
GET

http://localhost:8080/employees/delete/1


IMPORTANT HR NOTE:
This HR application is a Thymeleaf MVC application.
Use the browser form instead of sending arbitrary JSON to /employees/save.

The previous invalid JSON:

{
  "firstName": "Vivek",
  "lastName": "Singh",
  "email": "vivek@example.com",
  "role": "Developer",
  "departmentID": {
    "3"
  }
}

is invalid JSON.

Do not use that structure unless the actual Employee model in the project
defines those fields and an API endpoint accepts JSON.
