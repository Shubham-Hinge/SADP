===============================================================
Q1 - STUDENT REST API
===============================================================

TASK / QUESTION
---------------
Implement a Spring Boot Student REST Service with:
1. Add a student
2. Get all students
3. Get student by ID
4. Update student
5. Delete student
6. Validate student input

MAIN URL
--------
http://localhost:8081/api/students


Q1 - LINUX COMMANDS
--------------------

Go to the project:
cd ~/Downloads/ass5/q1

Check files:
ls

Check Java:
java -version

Check Maven:
mvn -version

Build:
./mvnw clean install

Run:
./mvnw spring-boot:run

Stop:
Ctrl + C


Q1 - THUNDER CLIENT
-------------------

1. ADD STUDENT

Method:
POST

URL:
http://localhost:8081/api/students

Header:
Content-Type: application/json

JSON:
{
  "name": "Vivek Singh",
  "email": "vivek@example.com",
  "course": "MSc Computer Science",
  "year": 1,
  "phone": "9876543210"
}


2. GET ALL STUDENTS

Method:
GET

URL:
http://localhost:8081/api/students

No body.


3. GET STUDENT BY ID

Method:
GET

URL:
http://localhost:8081/api/students/1

No body.


4. UPDATE STUDENT

Method:
PUT

URL:
http://localhost:8081/api/students/1

Header:
Content-Type: application/json

JSON:
{
  "name": "Vivek Singh Updated",
  "email": "vivek.updated@example.com",
  "course": "MSc Computer Science",
  "year": 2,
  "phone": "9876543210"
}


5. DELETE STUDENT

Method:
DELETE

URL:
http://localhost:8081/api/students/1

No body.


6. VALIDATION TEST

Method:
POST

URL:
http://localhost:8081/api/students

JSON:
{
  "name": "",
  "email": "wrong-email",
  "course": "",
  "year": 5,
  "phone": "123"
}

Expected:
400 Bad Request with validation errors.
